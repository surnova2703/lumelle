# Lumelle AI — инструкция по установке

[English version](INSTALL_EN.md)

Lumelle ставится за четыре шага: Python, Ollama, модель и сам Lumelle. Интернет нужен только при установке, дальше всё работает офлайн. Выбери раздел своей системы.

## Что понадобится

Нужен компьютер с Windows 10+, macOS 12+ или Linux, от 8 ГБ памяти и около 15 ГБ свободного места. Модель выбирается под компьютер.

| Компьютер | Модель для текста | Место на диске |
| --- | --- | --- |
| Mac на Apple Silicon (M1–M4), 16 ГБ | `qwen3:8b` | ≈ 5 ГБ |
| Windows / Linux с видеокартой NVIDIA от 8 ГБ | `qwen3:8b` | ≈ 5 ГБ |
| Ноутбук без видеокарты, 8–16 ГБ | `qwen3:4b` | ≈ 2,5 ГБ |

Для работы с картинками нужна ещё одна модель: `qwen3-vl:8b` (≈ 6 ГБ) или `qwen3-vl:4b` для слабых компьютеров. Без неё всё остальное работает.

Архив с Lumelle можно скачать на GitHub (**Code → Download ZIP**) или получить от автора. Репозиторий сейчас приватный, поэтому другие люди по ссылке его не откроют.

## Windows

1. **Python.** Скачай установщик с [python.org/downloads](https://www.python.org/downloads/) и запусти. На первом экране обязательно поставь галочку **Add python.exe to PATH**, затем нажми **Install Now**.
2. **Ollama.** Скачай с [ollama.com/download](https://ollama.com/download) версию для Windows и установи. После установки значок ламы появится в трее справа внизу.
3. **Модель.** Открой «Командную строку» (Пуск → набери `cmd`) и введи команду из таблицы выше, например `ollama pull qwen3:8b`. По желанию добавь модель для картинок: `ollama pull qwen3-vl:8b`.
4. **Lumelle.** Распакуй архив: правый клик → **Извлечь всё**. Запускать прямо из ZIP нельзя.
5. **Запуск.** Дважды щёлкни `start.bat`. Если появится «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**.

Для слабого компьютера запускай из командной строки в папке Lumelle: `start.bat --model qwen3:4b`.

## macOS

1. **Python.** Открой Терминал (`Cmd + Пробел` → «Терминал») и введи `xcode-select --install`. В появившемся окне нажми **Установить**. Вместе с инструментами поставится Python. Проверка: `python3 --version`.
2. **Ollama.** Скачай с [ollama.com/download](https://ollama.com/download) версию для Mac, перенеси в «Программы» и запусти. Значок ламы появится в строке меню.
3. **Модель.** В Терминале: `ollama pull qwen3:8b` и, если нужны картинки, `ollama pull qwen3-vl:8b`.
4. **Lumelle.** Распакуй архив двойным щелчком и перенеси папку в удобное место, например в домашнюю папку.
5. **Запуск.** Дважды щёлкни `start.command`. В первый раз macOS может сказать, что файл от неизвестного разработчика: тогда правый клик по файлу → **Открыть** → **Открыть**.

Если файл не запускается, открой Терминал в папке Lumelle и введи `bash start.sh`.

## Linux

Команды для Ubuntu и Debian; в других дистрибутивах пакеты называются так же.

1. **Python:** `sudo apt install python3 python3-venv`
2. **Ollama:** `curl -fsSL https://ollama.com/install.sh | sh`. Служба запустится сама.
3. **Модель:** `ollama pull qwen3:8b` (или `qwen3:4b`), для картинок `ollama pull qwen3-vl:8b`.
4. **Lumelle:** распакуй архив и перейди в папку: `cd lumelle`.
5. **Запуск:** `./start.sh` (если нет прав на запуск: `bash start.sh`).

На компьютере с NVIDIA сначала поставь драйвер видеокарты: тогда Ollama будет работать через неё и заметно быстрее.

## Первый запуск

Первый запуск идёт 1–3 минуты: скрипт создаёт окружение Python и ставит библиотеки. Потом он проверяет Ollama и модели и открывает Lumelle в браузере по адресу http://127.0.0.1:8000. Следующие запуски занимают пару секунд и работают без интернета.

Окно с текстом не закрывай, пока пользуешься Lumelle. Остановить: `Ctrl + C` или просто закрыть окно.

**Вход.** В Lumelle два аккаунта: `admin` (владелец, пароль `admin`) и `guest` (гость, пароль `guest`). У каждого свои чаты. Пароли простые, поэтому сразу смени их: войди как admin и нажми 👥 внизу боковой панели. Там же можно добавить новых пользователей: у каждого будут свои чаты, а временный пароль человек сменит при первом входе.

| Параметр | Что делает |
| --- | --- |
| `--model qwen3:4b` | другая модель для текста |
| `--vision-model qwen3-vl:4b` | другая модель для картинок |
| `--lan` | доступ с других устройств в той же сети |
| `--port 9000` | другой порт, если 8000 занят |
| `--no-browser` | не открывать браузер автоматически |

Параметры дописываются к команде запуска: `start.bat --lan` на Windows или `./start.sh --lan` на macOS и Linux.

### С телефона или планшета

1. Запусти Lumelle на компьютере с параметром `--lan`.
2. В окне запуска появится строка `From other devices: http://192.168.…:8000`.
3. Открой этот адрес в браузере телефона (iPhone или Android), подключённого к той же Wi‑Fi.
4. Добавь страницу на экран «Домой», чтобы Lumelle открывался как приложение.

Пока стоят пароли по умолчанию, `--lan` стоит включать только в домашней сети или через Tailscale. В кафе и общежитии твои чаты смогут открыть чужие люди.

## Документы

Слева нажми **«Документы»** и загрузи файлы: .docx, .pdf, .xlsx, .txt или .md, до 15 МБ. Внизу включи **«По моим документам»**. Теперь Lumelle ищет ответ в твоих файлах, а под ответом пишет, откуда он: 📎 имя файла — номер фрагмента. Поиск работает без интернета и без отдельной модели. Спрашивай на том же языке, на котором написан документ. Сканы PDF без текста не читаются. Документы видишь только ты.


**Папки.** В окне «Документы» сверху выбери **Папка → + Новая папка…** и назови её, например, «Диссертация». Новые файлы попадают в открытую папку, а переложить файл можно списком рядом с его названием. Внизу экрана рядом с «По моим документам» выбери, в какой папке искать.

**Только по документам.** Включи внизу **«Только по ним»**: тогда Lumelle отвечает только по твоим файлам, а если ответа в них нет, честно так и говорит, без догадок.

**Excel.** Таблицы .xlsx читаются по листам: каждая строка как «ячейка | ячейка». Формулы дают то значение, которое Excel сохранил последним.

**Поиск по смыслу.** Без него поиск идёт по словам. Чтобы Lumelle находила нужное, даже если в вопросе другие слова, один раз скачай модель (нужен интернет, ~0,6 ГБ):
```
ollama pull qwen3-embedding:0.6b
```
Потом поиск по смыслу работает без интернета, а уже загруженные файлы подготовятся сами (в окне «Документы» видно, сколько осталось).

## Наука и команды «/»

Режим **Science** — научный ассистент для диссертации. Он опирается на твои документы, отделяет их от общих знаний и не выдумывает источники: если источника нет, пишет [нужен источник].

Введи **«/»** в поле сообщения, и появится список команд. Их можно использовать в любом режиме:

| Команда | Что делает |
|---|---|
| `/план тема` | план диссертации: введение, главы и параграфы, заключение |
| `/обзор тема` | обзор литературы только по твоим документам (включи «По моим документам») |
| `/тест` + текст или скриншот | разбор теста: ответ, пошаговое объяснение, почему остальные варианты неверны |
| `/редактура` + текст | проверка как у научного руководителя: структура, стиль, таблица «Было → Стало → Почему» |

**Своя команда:** введи «/», выбери **«+ Своя команда…»**, придумай имя (например, `аннотация`) и напиши инструкцию. Удалить свою команду можно крестиком в том же списке.


## Онлайн-модели (по желанию)

Lumelle полностью работает без интернета. Но к ней можно подключить онлайн-модель по ключу: **GigaChat** (бесплатно для физлиц), Claude, ChatGPT или Perplexity: внизу экрана **Модель → ⚙ Онлайн-модели…**, вставьте ключ и нажмите «Сохранить». Lumelle проверит ключ и сама предложит модель. Потом выберите её в списке «Модель», рядом появится пометка «☁ Онлайн».

- **GigaChat (бесплатно):** откройте developers.sber.ru, войдите через Сбер ID, создайте проект GigaChat API для физлица (тариф Freemium) и скопируйте **ключ авторизации** (Authorization key). Сертификат Минцифры, который нужен GigaChat, уже лежит в папке `certs`, ставить его в систему не надо.
- Claude, ChatGPT, Perplexity: нужен пополненный баланс API, обычная подписка (Claude Pro, ChatGPT Plus) не подходит.
- Вопрос, история чата и найденные фрагменты документов уходят выбранной компании.
- Картинки и презентации всегда делает локальная модель. Гости всегда работают на локальной.
- Если связи нет, ответит локальная модель, а под ответом будет пометка.
- Ключ хранится только на этом компьютере, в файле lumelle.db.

## Голос

- **🔊 Прочитать вслух** под каждым ответом и галочка **«Читать ответы вслух»** внизу. Читают голоса системы (на Маке для русского — «Милена»), интернет не нужен. Больше голосов: Системные настройки → Универсальный доступ → Устный контент → Системный голос → Управлять голосами.
- **🎤 Сказать голосом:** нажми, говори, нажми ещё раз. Речь распознаёт модель Whisper прямо на компьютере. В первый раз она скачивается (около 0,5 ГБ), для этого нужен интернет. Если включена галочка «Читать ответы вслух», сказанное сразу отправляется, и Lumelle отвечает голосом — получается разговор.
- Модель поменьше и побыстрее: `--whisper-model base`; поточнее и помедленнее: `--whisper-model medium`.
- **Микрофон с телефона.** Браузеры дают микрофон только по защищённому адресу (https). Его даёт Tailscale: в его панели управления (login.tailscale.com → DNS) включи HTTPS Certificates, затем на Маке выполни
  `/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg 8000`
  и открывай на телефоне адрес вида `https://имя-мака.что-то.ts.net`, который покажет команда. Чтение вслух работает и без этого.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| `Python 3.9+ is required` или «'python' не является командой» | Переустанови Python с галочкой **Add python.exe to PATH** (Windows) или выполни `xcode-select --install` (macOS) |
| `Read timed out` или `Could not install the libraries` | Медленный интернет. Запусти скрипт ещё раз: уже скачанное не потеряется. Можно подключиться к другой сети |
| `Ollama is not running` | Запусти приложение Ollama (значок ламы должен появиться), на Linux: `ollama serve` |
| `Model qwen3:8b is not installed` | Выполни команду из сообщения, например `ollama pull qwen3:8b` |
| Ответы очень медленные | Возьми модель поменьше: `--model qwen3:4b`. Закрой тяжёлые программы. Галочку «Думать» включай только для сложных вопросов |
| Картинки не распознаются | Скачай модель для картинок: `ollama pull qwen3-vl:8b` |
| «Файл от неизвестного разработчика» (macOS) | Правый клик по `start.command` → **Открыть** |
| «Система Windows защитила ваш компьютер» | **Подробнее → Выполнить в любом случае** |
| `address already in use` | Порт 8000 занят: Lumelle уже запущен в другом окне или запусти с `--port 9000` |
| С телефона не открывается | Проверь `--lan` и одну Wi‑Fi; на Windows разреши Python в брандмауэре, когда он спросит |

## Как обновить и удалить

**Обновить.** Скачай новую версию и скопируй её файлы поверх старых с заменой. Чаты хранятся в файле `lumelle.db` и не пропадут. Если в новой версии появились библиотеки, удали файл `.venv/.deps-ok`: при следующем запуске они поставятся сами.

**Удалить.**

1. Удали папку Lumelle: вместе с ней удалятся окружение Python, чаты и созданные презентации.
2. Удали модели, чтобы освободить место: `ollama rm qwen3:8b` и `ollama rm qwen3-vl:8b`.
3. Если Ollama больше не нужна, удали её как обычную программу.
